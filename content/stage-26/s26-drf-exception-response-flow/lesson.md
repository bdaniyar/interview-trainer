## Теория

### Что это

Тема **DRF exception/response flow** описывает отдельный контракт backend-разработки.

### Как работает

Разложи механизм на вход, изменение состояния, наблюдаемый результат и специфичный для темы сценарий ошибки.

**DRF exception/response flow.** `DRF exception/response flow` входит в Django/DRF обработка запроса и влияет на ORM query count, validation, permissions или сериализация ответа.


### Важный нюанс / ограничение

Граница Junior: уверенно объясняй `DRF exception/response flow` и `DRF exception/response flow` на одном проверяемом примере; редкие внутренние детали сначала ищи в официальной документации.

### Где используется в backend

В backend эта тема важна в том месте, где применяется `DRF exception/response flow`; проверяй именно наблюдаемый contract, а не название инструмента.

## Модель понимания

Проект Django содержит конфигурацию, приложения группируют доменную возможность, Сериализатор DRF задаёт API boundary.

Используй эту модель как короткую опору, затем проверяй её конкретным примером из теории.
