## Теория

### Что это

Тема **merge** описывает отдельный контракт backend-разработки.

### Как работает

Разложи механизм на вход, изменение состояния, наблюдаемый результат и специфичный для темы сценарий ошибки.

**fast-forward.** `fast-forward` меняет одно из состояний Git: working tree, index, branch pointer или shared history; эти эффекты нельзя смешивать.

**merge commit.** `merge commit` меняет одно из состояний Git: working tree, index, branch pointer или shared history; эти эффекты нельзя смешивать.

**conflicts.** `conflicts` меняет одно из состояний Git: working tree, index, branch pointer или shared history; эти эффекты нельзя смешивать.


### Важный нюанс / ограничение

Граница Junior: уверенно объясняй `fast-forward` и `merge commit` на одном проверяемом примере; редкие внутренние детали сначала ищи в официальной документации.

### Где используется в backend

В backend эта тема важна в том месте, где применяется `fast-forward`; проверяй именно наблюдаемый contract, а не название инструмента.
