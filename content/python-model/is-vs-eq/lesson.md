## Теория

### Что это

`==` сравнивает значения по протоколу равенства, а `is` проверяет, являются ли два выражения ссылками на один и тот же объект. Равные объекты не обязаны быть одним объектом.

### Как работает

Для `left == right` Python вызывает реализацию `__eq__`; пользовательский класс может определить собственное понятие равенства. `left is right` не вызывает методы объекта и сравнивает identity. `id(obj)` возвращает идентификатор, уникальный среди живых объектов текущего процесса.


### Пример

```python
a = [1, 2]
b = [1, 2]
c = a

print(a == b)  # True
print(a is b)  # False
print(a is c)  # True
```

### Важный нюанс / ограничение

Сравнивай с `None` через `is None`: `None` — singleton, а пользовательский `__eq__` может вести себя неожиданно. Не используй `is` для строк и чисел: interning — оптимизация реализации, не контракт программы.

## Модель понимания

Отделяй identity объекта, его value и binding имени. Assignment обычно создаёт новую связь, а не копию.

## Примеры кода

### Identity and equality: отдельный пример

```python
left = [1, 2]
right = [1, 2]
same = left

print(left == right)
print(left is right)
print(left is same)
```

`==` вызывает equality protocol, а `is` сравнивает identity объектов.

## Типичные ошибки

### Ошибка 1

`status is 'paid'` может случайно сработать в одном запуске и сломаться в другом; для значения нужна проверка `status == 'paid'`.

### Ошибка 2

`value == None` способен вызвать переопределённый `__eq__`; точнее писать `value is None`.

## Хорошие ответы

### Короткий ответ

`==` сравнивает значения, `is` — identity объектов. С `None` используют `is`, потому что это singleton.

### Нормальный ответ уровня Junior

> `==` проверяет равенство значений и обычно вызывает `__eq__`. `is` отвечает на другой вопрос: ссылаются ли оба имени на один объект. Поэтому два списка `[1]` равны через `==`, но обычно не идентичны. С `None` пишут `is None`: это точно выражает identity-проверку и не вызывает чужой `__eq__`.

### Углубление / дополнительный вопрос

**Почему нельзя проверять строки через `is`?**

Python может интернировать некоторые строки, но это не гарантируется для произвольных значений; сравнение значения должно использовать `==`.
