## Примеры кода

### Array/list: отдельный пример

```python
rows = [('a', 2), ('b', 1), ('c', 2)]
print(sorted(rows, key=lambda row: row[1]))
```

Expected: `[('b', 1), ('a', 2), ('c', 2)]`. При равных keys sorted сохраняет исходный относительный порядок элементов.
