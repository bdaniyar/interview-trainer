# Два нейронных слоя и прямой проход

Для расчёта оценки риска у сервиса есть два признака. Вместо одной прямой введём два слоя. Посчитаем сеть на бумаге и посмотрим, где её поведение перестаёт быть линейным.

## Учебные цели

- Рассчитать два слоя с проверкой размеров.
- Показать эффект ReLU и зафиксировать неизменность параметров при inference.
- Посчитать производную по одному весу и проверить её численно.

## Теория

**Нейрон** вычисляет сумму взвешенных входов плюс bias. Для входа x размера n и h скрытых нейронов форма W₁ — (h,n), b₁ — (h,). Первое вычисление z = W₁x + b₁ даёт h чисел. **Активация** меняет каждое число. ReLU(t)=max(0,t), поэтому пропускает положительное значение и обнуляет отрицательное. a = ReLU(z) — скрытое представление. Для m выходов W₂ имеет форму (m,h), b₂ — (m,), выход y = W₂a + b₂. Последовательность вычислений называется прямым проходом, forward propagation.

Умножение двух линейных преобразований остаётся линейным, а их сочетание со смещениями даёт одно аффинное преобразование. Без ReLU можно свернуть `W₂(W₁x+b₁)+b₂` в `(W₂W₁)x+(W₂b₁+b₂)`. ReLU отделяет области входа, в которых один скрытый нейрон активен, от областей, где он выключен.

Возьмём x=[2,−1], W₁=[[1,2],[−1,1]], b₁=[1,2]. Первые суммы 2−2+1=1 и −2−1+2=−1, значит a=[1,0]. W₂=[[3,4]], b₂=[−2], результат [1]. Если изменить W₁[0][0] на ε, первый z растёт на 2ε, а результат на 6ε. Для второго скрытого слоя при этом входе производная равна нулю, пока z остаётся отрицательным.

В **вычислительном графе** узлы представляют промежуточные значения, рёбра показывают зависимости. Цепное правило перемножает локальные производные вдоль пути. Для одного веса путь xᵢ → zⱼ → aⱼ → yₖ даёт dyₖ/dW₁[j][i] = W₂[k][j]·1(zⱼ>0)·xᵢ. Индикатор равен единице при положительном z и нулю при отрицательном. Точка z=0 — излом, где обычной производной нет. **Backpropagation** применяет цепное правило от потерь к параметрам, суммируя вклад путей. В упражнении нет полного backward или подгонки модели.

## Модель понимания

Каждый слой читает вход, веса и смещения. Inference вычисляет новый результат без записи в параметры. Training отдельно вычисляет loss и обновляет параметры.

## Что нужно знать на Junior

Сверяй количество строк bias, ширину матрицы и промежуточный shape. Для конечных разностей двигай один вес в обе стороны на ε и бери ровно тот же выход. Проверь, что обе точки остались в гладкой области.

## Примеры кода

```python
def response(weight):
    signal = weight * 2 + 1
    return max(signal, 0) * 3 - 2
eps = 1e-5
slope = (response(1+eps)-response(1-eps))/(2*eps)
assert abs(slope-6)<1e-8
assert response(-1)==-2
print(round(slope,5))
```

Вывод `6.0`. Градиент относится к выбранному весу и текущему входу. При отрицательном скрытом сигнале тот же путь перестаёт влиять на результат.

## Типичные ошибки

- Применять ReLU к финальному выходу без контракта.
- Смешивать оси входа и нейронов.
- Мутировать веса во время forward.
- Сверять производную прямо на изломе.

## Вопросы с собеседований

1. Почему два линейных слоя дают один?
2. Как найти чувствительность одного веса?

## Хорошие ответы

**Почему два линейных слоя дают один?**

Матрицы можно перемножить, смещения объединить. ReLU делает преобразование кусочно-линейным. Граница проходит там, где меняется знак скрытого preactivation.

**Как найти чувствительность одного веса?**

Для выбранного первого веса нужны входная компонента, наклон активации и вес второго слоя. Сравнить с центральной конечной разностью вне излома.

## Критерии хорошего ответа

Выпиши формы обеих матриц, считай один путь по числам и раздели прямой проход и обновление параметров.

## Задача

Реализуй `forward(x,w1,b1,w2,b2)` и `sensitivity(x,w1,b1,w2,b2,output,hidden,feature)`. Первый возвращает вектор без выходной ReLU. Второй — аналитическая локальная производная выбранного выхода по `w1[hidden][feature]`, индексы с нуля. Например, x=[3], w1=[[2]], b1=[0], w2=[[5]], b2=[0] дают [30] и чувствительность 15. Слои и вход непустые, значения конечны, несогласованные shapes, неверные индексы и излом дают ValueError. Входные параметры неизменны. Check сдвигает выбранный вес в двух направлениях и оценивает отклонение.
