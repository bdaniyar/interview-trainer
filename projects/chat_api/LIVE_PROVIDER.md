# Опциональная локальная проверка OpenAI Responses

Приложение P1 запускается с `ScriptedProvider`. Для эксперимента с живым API используй отдельную версию SDK и только свой синтетический вопрос. Сначала проверь доступную модель, лимиты и текущую цену. Единичный запрос может тарифицироваться. Пример SDK проверен офлайн через MockTransport, живой запрос в проверку релиза не входил.

Из корня репозитория создай [среду SDK](../../tools/ai_sdk_verify/README.md). Передай в окружение процесса `OPENAI_API_KEY` из хранилища секретов и `OPENAI_MODEL` с доступной для твоего аккаунта моделью. Затем явно запусти:

```sh
/tmp/pythoria-sdk-check/bin/python tools/ai_sdk_verify/live_example.py --live
```

SDK использует серверные переменные окружения. Этот пример запускается отдельно от Pythoria и не принимает ключ из браузера, Monaco или DTO. Чтобы заменить провайдер внутри локального P1, реализуй протокол из `contracts.py` и проверь его теми же офлайн-тестами.
