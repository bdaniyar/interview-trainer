# Опциональный OpenAI Responses API

Стандартный P2 использует локальный provider. В отдельной авторской среде есть проверенный пример `tools/ai_sdk_verify/structured.py`. В `parse_trip` передаются AsyncOpenAI, модель и строка. SDK читает внешний ключ из окружения, а модель выбирается явно. Любой реальный вызов требует отдельного решения о доступе, стоимости и данных.

Для локального адаптера используй `Provider.extract` из `contracts.py`. Передай instructions и отдельный input, извлеки typed `output_parsed`, проверь отказ и состояние генерации до принятия DTO, затем переведи ошибки в ProviderReply. Сохрани P2 domain validator. Оборванный JSON может вызвать ValidationError уже внутри SDK parse. Если важно сохранить именно incomplete, получи статус без автопарсинга и валидируй только завершённый payload. Один уровень повторов и общий deadline задаёт приложение; если оно управляет повторами, в SDK ставят `max_retries=0`.

Запуск [закреплённых MockTransport тестов](../../tools/ai_sdk_verify/README.md) не требует ключа. Применимость конкретной живой модели, ровно тот же subset схемы и качество извлечения проверяются отдельно. Для эксперимента используй только синтетический текст и отдельный бюджет. P2 и тесты не включают live adapter по умолчанию.
