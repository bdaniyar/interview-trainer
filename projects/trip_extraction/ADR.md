# ADR 01. Типизированная граница провайдера

**Решение.** Приложение владеет Prompt, ProviderReply и ExtractResult. Внешний адаптер реализует один async метод. Он сообщает тип неуспеха и payload, если он применим. Используем отдельные wire-schema и TripRequest. FastAPI получает реализацию через dependency injection.

**Причины.** Returned JSON проверяет форму. Строгие даты, порядок дат, допустимое значение гостей и защита unknown — правила приложения. Внешние SDK различаются схемами, способами сигнализировать отказ и поведением при обрыве. Dependency injection позволяет подставить scripted provider и протестировать cancellation, повтор и исходы через настоящие ASGI-запросы.

**Границы.** Адаптер передаёт исход, приложение определяет правила доступа и лимит повторов. Приложение обрабатывает исключения провайдера на внешней границе и возвращает безопасную категорию. Неизвестные эффекты timeout и сломанные даты остаются отдельными исходами. Нужна отдельная проверка фактической точности, в том числе когда все поля валидны.
