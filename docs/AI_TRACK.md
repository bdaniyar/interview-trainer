# AI Engineering в Pythoria

Выбери **AI Engineering** в верхней панели. Список, поиск, кнопки перехода и процент относятся к выбранному треку. У AI есть сворачиваемый план по этапам. Только опубликованные уроки открываются и входят в процент. На прямой ссылке `/?lesson=ai01-ai-roles-and-boundaries` трек определяется по уроку. В этом браузере сохраняется последний AI-урок. Backend продолжает хранить последний открытый урок в SQLite.

AI1.2 открывает R0. В правой панели реши упражнение и запусти публичные сценарии через Run. Эта практика завершается самостоятельной отметкой после теории и разбором своей аргументации. Она начисляет существующие 5 XP за теорию. Глобальный XP и старые ключи прогресса сохраняются. Конспект из «Шпаргалки» можно скачать в Markdown вместе с источниками.

`content/ai_curriculum.json` описывает десять этапов и 29 опубликованных уроков. Ещё 43 урока отражены в плане. AI использует общий загрузчик, редактор, изолированный Python Runner и SQLite. `content/course.json` содержит выгрузку 370 опубликованных уроков Backend. Состав AI и количество запланированных уроков отдаёт поле `ai` в `GET /api/course`.

Описание этапов и образовательные контракты находятся в [AI Curriculum Plan](AI_CURRICULUM_PLAN.md). Для AI2.8 и AI3.3 запрос Phase 10 задал более поздние явные ID, `ai-engineering.02.08.context-window-and-token-budget` и `ai-engineering.03.03.async-provider-lifecycle`. Slug AI2.8 сохраняет значение плана `ai02-context-window-budget`. Обе карточки сохраняют исходную тему и зависимости.

AI1.1 и AI1.3 — диагностика и практика. В AI1.1 публичный пример использует FastAPI TestClient с синтетическими владельцами бесед. В AI1.3 сервис получает типизированные результаты сменных fake-адаптеров. API, провайдер и активная база данных для этих упражнений не нужны. Для проверки всех опубликованных Python-упражнений через настоящий Runner на одноразовом Compose-стеке используй `python3 scripts/smoke_ai_runtime.py`.

AI2.1, AI2.5, AI2.8 и AI2.10 подготавливают к API. Упражнения работают с синтетическими данными, двумя учебными словарями, атомарной историей и локальным генератором случайных чисел. Run показывает публичные результаты. Это самостоятельная практика с конспектом и разбором, без скрытой оценки mastery.

AI3.1–AI3.4 используют Check для типов результата, request DTO, lifecycle и ограниченных повторов. Терминал сообщает прогресс по сценариям, а hidden fixtures и traceback остаются вне ученического интерфейса. Названия и данные скрытых cases предназначены для педагогического скрытия. Код ученика и тесты по-прежнему выполняются в одном изолированном контейнере, поэтому тестовые данные синтетические. SDK-проверка проводится в [отдельном окружении](../tools/ai_sdk_verify/README.md).

## R0

AI3.5–AI3.8 завершают трек потоковыми событиями, оценкой расхода, FastAPI Chat API и контрактными тестами. Проект [P1 LLM Chat API](../projects/chat_api/README.md) запускает `POST /chat` и `POST /chat/stream` с локальным provider. В AI3.8 Run проверяет здоровый сервис и намеренно сломанный отказ. Check подставляет другие данные и одиночные дефекты.

| Поставка | Уроки | Исполняемые проверки упражнения |
| --- | --- | --- |
| 10A | AI1.2 | 6 открытых и 10 дополнительных авторских случаев; рубрика решения |
| 10B | AI1.1 и AI1.3 | 8 и 9 авторских случаев диагностики и границы адаптера |
| 10C | AI2.1, AI2.5, AI2.8, AI2.10 | 5, 9, 3, 9 авторских случаев на данные, токены, окно и sampling |
| 10D | AI3.1–AI3.4 | 11, 10, 4, 9 скрытых сценариев |
| 10E | AI3.5–AI3.8 | 7, 12, 10, 14 скрытых сценариев |

**Редакционная проверка** выполнена автором 2026-11-21 по разделу 15 плана. Источник и применимость хранятся рядом с каждым уроком. Открытые примеры показывают механизм на других входах, чем самостоятельная задача. Конспект содержит объяснение, пример, вопросы и сворачиваемую сверку. Проверка ссылок отличается от проверки кода. Python-примеры и эталоны выполняет `tools/validate_content.py --run-solutions`. Отдельный SDK-прогон проверяет реальные типы, ошибки и SSE через MockTransport. Оценка качества реальной модели остаётся самостоятельной задачей.
